DPI 고르는 법

300: 전단·브로셔·명함 같은 가까이서 보는 인쇄물
150: 포스터·배너처럼 조금 떨어져서 보는 것
72~100: 현수막처럼 멀리서 보는 큰 출력물

재단 여유(도련)는 잘릴 때 흰 테두리가 생기지 않게 바깥에 더 그리는 부분이에요. 보통 한쪽에 2~3mm예요. 정확한 값은 인쇄소 안내를 따르세요.
